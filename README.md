# Starter Kit: Rekap Pengeluaran (Angular)

Project Angular polos untuk latihan komponen. Sudah berisi:

- Angular 22 (standalone, signals), Bootstrap 5 (sudah dipasang di `angular.json`)
- `src/app/data/expenses.ts`: tipe `Expense`, `Category`, anggaran `BUDGET`, dan 12 transaksi
  contoh (fiktif)
- `src/app/app.config.ts`: bahasa Indonesia untuk pipe `currency` dan `date`
- `src/app/app.ts` dan `app.html`: hanya judul "Rekap Pengeluaran"

Komponen (`src/app/components/`) kamu buat sendiri mengikuti panduan PDF.

Cara pakai (butuh Node.js 22.22.3+ atau 24.15+ untuk Angular CLI 22):

    npm install
    npm start

Lalu buka http://localhost:4200.
